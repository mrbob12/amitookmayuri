# Amit & Mayuri — Royal Wedding Invitation Website 💍✨

A luxury, interactive wedding invitation web application crafted for **Amit & Mayuri**, inspired by traditional Indian royal wedding elegance with modern interactivity.

---

## 🌟 Key Features

1. **Royal Aesthetic & Visual Elegance**
   - Traditional Indian royal arch framing (Jharokha style)
   - Bodhi Tree / Meditating spiritual silhouette emblem & sacred Lotus motifs
   - Falling rose & bougainvillea flower petals animation
   - Champagne, Burgundy Maroon (`#7A2036`), and Gold Foil gradient palette

2. **Dual Celebrations Coverage**
   - **Wedding Ceremony (Lagna Samarambh)**:
     - 📅 **Sunday, 10 January 2027 • 6:00 PM Onwards**
     - 📍 **B.S. Butala Bhavan Sundarwadi, Mahad, Raigad, Maharashtra**
     - 🚆 Transit Info: Mumbai-Goa Highway • Mangaon Railway Station (32 km)
   - **Grand Wedding Reception (Sneha Sammelan)**:
     - 📅 **Wednesday, 13 January 2027 • 6:00 PM Onwards**
     - 📍 **Queen's Land Celebration Lawn & Banquet, Hudkeshwar Outer Ring Road, Nagpur, Maharashtra**
     - 🚗 Transit Info: Prime Nagpur Outer Ring Road location with valet parking

3. **Smart Interactive Tools**
   - ⏳ **Dual-Mode Live Countdown Timer**: Switchable countdowns for both Mahad Wedding and Nagpur Reception.
   - 📅 **Calendar Sync**: One-click "Add to Google Calendar" and Apple/Outlook `.ics` download for both events.
   - 🗺️ **One-Tap Google Maps Navigation**: Direct navigation buttons for both venues.
   - 🔍 **HD Invitation Card Lightbox**: Guests can view and download the original invitation cards.
   - 🎶 **Traditional Wedding Shehnai & Mangalashtak Player**: Gentle auto-play on first scroll/interaction, floating disc controller, and navbar toggle.
   - 💬 **Interactive WhatsApp RSVP**: Form submits locally and automatically prepares a formatted WhatsApp confirmation to send to the host.
   - 🌸 **Live Blessings Wall**: Guests can leave warm wishes directly visible on the page.

## 🚀 How to Run Locally

You can preview the website immediately using any local static web server:

```bash
cd wedding-invitation
python3 -m http.server 3000
```
Then open `http://localhost:3000` in your web browser.

---

## 🌐 Deploy to Vercel (One-Click)

1. Install Vercel CLI (if not already installed):
   ```bash
   npm i -g vercel
   ```
2. In the `wedding-invitation` folder, simply run:
   ```bash
   cd wedding-invitation
   vercel
   ```
3. Follow the quick prompts to get a live URL (e.g., `https://amit-mayuri-wedding.vercel.app`) to share with friends and family!
